Before you start
  • Export any run reports you must keep, before your old licence ends.
  • Connect Jira first, so linked issues come across where your source supports it.
  • Plan seats and user access separately. Users are set up apart from the test data.
  • Create the custom fields you need before a CSV import.

Migrations are one-time imports, not a continuous sync. CSV files are limited to 10 MB each, so split large ones. On the Zephyr and CSV paths, folder names over 100 characters and tags over 48 are shortened.
