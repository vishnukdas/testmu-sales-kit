3 · Migration runbook
Inventory

List every test: tool, .jmx and CSV files, plugins, thread groups, regions, peak users, duration, how it is triggered, and any failure criteria or APM hooks.

Export

Download the .jmx and data files from BlazeMeter (or the repo). For Taurus-only tests, export the generated .jmx. Export run history and baseline numbers before the contract ends.

Dry run

Upload to a HyperExecute project and run each script at 5 to 10 percent of target load in one region. Any plugin or sampler failure shows up here.

Parity run

Run at target load with the Total Load Distribution override on. Compare p90, throughput and error rate against the last BlazeMeter baseline for the same build.

Wire the pipeline

Gatling and k6: add hyperexecute.yaml and the CLI step. JMeter: schedule nightly runs with Workflows.

Cut over at renewal

Keep BlazeMeter for anything still blocked (Locust, Private Locations, peak-event scale) and move the rest before the renewal date.
