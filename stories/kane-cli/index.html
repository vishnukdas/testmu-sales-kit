Run it
Same sentence. A developer, a pipeline or an agent runs it.

    

  

    

    

  

  
Saved tests replay unchanged steps from cache with no LLM cost. When a step breaks, Kane CLI tries the direct path, then re-derives the route from the objective, then a fresh session, before handing the failure to root cause analysis. Simulated example.






  
Beyond the click
It checks what users see, and what they don't.
Simulated example

  

    
checkpoints

    

  

  
Checkpoint types: assertion, if/else and extraction. Kane CLI picks the analyze method: visual (screenshot), textual DOM, URL, title, or DevTools for network, console, performance, cookies and local storage. Bug detection can be set to off, stop or continue.
